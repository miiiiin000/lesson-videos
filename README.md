# 授業動画視聴サイト（GitHub Pages用）

## 公開
1. GitHubにPublicリポジトリ（例：lesson-videos）を作成します。
2. index.html、group-a.html、group-b.html、group-c.html、group-d.html、style.css をリポジトリ直下へアップロードします。ZIPをそのままアップロードしないでください。
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save。
4. 公開URL例: https://ユーザー名.github.io/lesson-videos/

## グループ別URL
- A: https://ユーザー名.github.io/lesson-videos/group-a.html
- B: https://ユーザー名.github.io/lesson-videos/group-b.html
- C: https://ユーザー名.github.io/lesson-videos/group-c.html
- D: https://ユーザー名.github.io/lesson-videos/group-d.html

## 注意
- Google Driveの動画は個別に「リンクを知っている全員・閲覧者」にする必要があります。
- シークレットウィンドウで動画が再生できるか確認してください。
- 画面の「動画②へ進む」は視聴完了を検知するものではありません。視聴時間・ログ取得・アクセス制御は行いません。
- GitHub Pagesは公開サイトです。グループ別URLを分けても他のグループへのアクセスを技術的に禁止できません。
- ページ内の再生はGoogle Driveの利用条件・共有権限・ブラウザ設定に依存します。
